# Features

One pair of files per roadmap milestone, written by the `spec` skill before any code:

- `<feature>-requirements.md`: what must be true when it is done, its events, out of scope,
  open questions.
- `<feature>-plan.md`: the phased plan, with the files, changes and how to verify each phase.
- `<feature>-research.md`, sometimes: the research a large feature was chosen from (the market,
  the options and their cost), kept beside its spec.

Name `<feature>` after the milestone (for example `m3-create-your-pet`). The product doc
([`../product.md`](../product.md)), the [roadmap](../roadmap.md) and the
[screen spec](../UI/kinpaw-screen-spec-v1.md) are the inputs.
