Mert raises new ideas while we build. For each one: **store it** in
`docs/application/ideas.md` (what, why, edge cases, status), **advise** (a recommendation, the
edge cases, how it would be implemented), and keep following the roadmap's milestones unless he
picks it up. Then build **step by step**: one phase at a time, and before moving on, confirm
the step's logic, tables and screens with him.

**Why:** Mert said so on 2026-10-01: "no need to complete everything on one shot ... verify with
me steps, logic, tables, and move on."

**How to apply:** end each phase with what was done, how it was checked, and the next step,
then wait for his go. Never build ahead of an unanswered question. This adds to
[[scope-check-before-building]] and [[git-by-mert]].
